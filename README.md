# motormaxxing
References and Examples for Actuator Crafting. 
Self-learning and practice of applying the principles described in _Brushless PM Motor Design_ by Duane Hanselman (1994).
This repository contains the following sub-projects:

**1. Python Winding Calculator**
An interactive Python tool for hand-winding your stators.
Inputs: Copper AWG, copper thermal resistance, stator tooth area, current target, KV target
Output: Turns per tooth, strands per bundle.
